# ひより日和 · 日程小島

用 three.js 打造的遊戲化日程／工作／專案管理 App。你的一天是一座漂浮在雲海上的小島，風格走日系清透路線。

```bash
npm install
npm run dev      # http://localhost:5199
npm run build    # 輸出到 dist/
npm test         # 單元測試（Vitest）
```

## 玩法

| 你做的事 | 小島上發生的事 |
| --- | --- |
| 新增任務 | 花圃長出一株花苞（顏色＝分類，大小＝優先度） |
| 完成任務 | 花苞綻放，吉祥物もち跳過去慶祝，獲得 XP |
| 一天的任務全部完成（≥3 個） | 「完美的一天」＋40 XP、花圃放煙火 |
| 新增日程 | 小島外圈「時之環」亮起一段光帶（0 點在後、12 點在前，光點是現在時刻） |
| 建立專案 | 島上的空地立起一座塔的藍圖 |
| 完成里程碑 | 塔往上蓋一層；全部完成時塔頂裝上金色相輪並施放煙火 |
| 番茄鐘（25＋5 分） | もち跳回小木屋、擠進門裡，畫面跟著進到屋內，看もち在矮桌前讀書陪你；結束時伸個懶腰、開門出來，屋頂升起一盞天燈 |
| 升級 | 解鎖島上的新風景：石燈籠、鳥居、太鼓橋、繡球花、小祠、漂浮燈籠、浮空小島… |

另外還有每日任務（左下角，可領 XP）、連續打卡天數、39 枚成就印章、最近七天紀錄。天空會依真實時間從清晨、白天、黃昏一路變成星空夜晚，介面也會跟著換成夜間玻璃。

### 遊戲性

- **今日の本命**：按任務旁的 ☆（或快速輸入打 `★`、`!本命`）挑出每天最重要的 3 件，完成雙倍 XP，三件全清再 +30 XP；花苞上會飄一顆小金星。一天完成超過 8 件後，任務 XP 減半——鼓勵休息，也讓灌任務刷分不划算
- **花の図鑑**：每完成一個任務就開出一朵花，共 26 種，分常見／少見／稀有／傳說。開什麼花看分類、時段、季節、是否本命、有沒有專注過、連續天數……本命任務的稀有機率加倍。紀錄頁可以看圖鑑與未發現花的線索
- **輪替的每日任務**：每天從 15 個題庫依日期抽 3 個（簡單／普通／挑戰各一），不會抽到當天做不到的
- **每週挑戰**：每週一個較大的目標，達成可拿每週限定擺飾（共 6 件，第一件免費）
- **逾期的花會垂下**：最近 7 天沒完成的任務會出現在今天的花圃裡、低頭褪色；完成或移到今天就慢慢挺回來（不扣 XP）
- **お守り**：在商店用金平糖買，漏掉一天時自動保住連續天數，最多帶 2 個
- **等級延伸到 30**：每兩級擴建一次小島——大櫻花樹、島緣瀑布、夜櫻雪洞、茶屋浮島、神社、紙鶴群、彩虹橋、賞月台、雲鯨、星之大樹；商店的擺飾也會依等級陸續上架，另有季節限定品
- **もち的好感度**：摸摸、專注、回顧、清完本命、每天來看看牠都會累積。10 個等級解鎖 6 套衣裝，還有新動作：偶爾去花圃澆水、專注時影子映在小木屋紙窗上陪你、每天送幾顆金平糖
- **專案期限**：在期限前落成額外 +60 XP，塔頂多兩圈金色光環；剩 2 天內的塔前會亮紅燈籠
- **上週回顧卡**：每週一第一次打開時，回顧上週的開花數、專注、本命、心情與新發現的花

### 其他功能

- **一行快速輸入**：在任務欄直接打 `明天下午3點到5點 設計週會 #工作 !高`，下方會即時預覽解析結果；有時間的會變成日程，沒有的變成任務。支援 今天／明天／後天、`下週三`、`5天後`、`11/3`、`2027-02-03`、`晚上8點半`、`14:00-15:30`、`9am`、`30分鐘`、`2小時`、`每天`／`平日`／`每週一三五`、`#分類`、`!高` 或 `!!!`
- **例行公事**：任務和日程都可以設成每天、平日或每週幾。每天自動長出當天的那一份；刪掉某一天的不會再長回來
- **日程提醒**：開始前 0／5／10／15／30 分鐘提醒（もち說話、提示卡、音效），可開啟系統通知
- **拖曳時之環**：直接拖光帶就能改時間，拖兩端可以改長度
- **四季**：依日期換成春櫻、夏綠、秋楓、冬雪，花圃、樹冠、飄落粒子和もち的圍巾都會換季
- **金平糖商店**：完成任務會同時拿到金平糖（約 XP 的五分之一），可以買 35 種擺飾放在島上任何空地；點擺飾可以移動或收回（退一半）
- **番茄鐘綁定任務**：專注時選一件任務，那朵花外圈會亮起金環，每完成一輪就長大一點
- **晚間回顧**：晚上 9 點後邀請你用天氣（晴／虹／星／曇／雨）記下今天的心情和一句話，紀錄頁會變成小日記
- **省電模式**：閒置時把畫面更新率降到 30／15 fps，有動畫或操作時立刻回到全速
- **安裝成 App（PWA）**：正式版可以安裝到桌面或手機主畫面，離線也能打開

## 操作

- 拖曳旋轉、滾輪縮放；點花／塔／時之環上的光帶，可以跳到對應的清單項目
- 點もち可以摸摸牠
- 清單裡點任務標題，鏡頭會飛到那朵花；點優先度或分類標籤可以直接切換
- 鍵盤：`N` 新增任務、`F` 開始／暫停專注、`V` 回到全景（在小木屋裡時回到小島）、`S` 開關商店、`←` `→` 切換日期、`1`–`4` 切換分頁、`Esc` 關閉
- 放置擺飾時：移動滑鼠選位置、點一下放下、`R` 旋轉、`Esc` 取消

## 資料與同步

資料都存在瀏覽器的 localStorage。在「紀錄 → 設定」可以：

- **匯出／匯入** JSON 備份，或重置小島
- **雲端同步**（電腦版 Chrome／Edge）：選一個放在 OneDrive、Dropbox、Google 雲端硬碟同步資料夾裡的檔案，之後每次變更都會自動寫進去；回到視窗或每分鐘會檢查有沒有別台裝置的新資料。第一台按「建立同步檔」，其他電腦按「連結既有檔案」選同一個檔案
  - 只有一邊改過：自動用新的那一邊
  - 兩邊都改過（例如兩台都在離線時用過）：不會自動覆蓋，會請你選「用雲端的」或「用這台的」
  - 被取代的那一份會留一份備份，可以按「還原備份」拿回來
  - 瀏覽器重開後可能要按一次「繼續同步」重新授權（瀏覽器的安全規定）
  - 手機瀏覽器和 Firefox 不支援直接存取檔案，請用匯出／匯入

這個同步不需要任何伺服器。如果想要手機也能即時同步，需要接一個真正的後端（例如 Supabase 或 Firebase）：要有你自己的帳號、專案網址和金鑰，再把 `src/sync.js` 的讀寫換成 API 呼叫，判斷新舊的邏輯可以沿用。

## 開發用參數

- `?hour=20.5`：預覽指定時刻的天色（不影響資料）
- `?season=winter`：預覽指定季節（spring／summer／autumn／winter）
- `?focus=0.1`：番茄鐘縮短成 0.1 分鐘，方便測試（只在 `npm run dev` 有效）
- Console 裡的 `hiyori.store`、`hiyori.fileSync`、`hiyori.sky.hourOverride = 6` 可以直接操作

## 結構

```
src/
  main.js          把資料事件接到 3D 演出與 UI
  store.js         狀態、XP／等級、金平糖、連續天數、成就、每日任務、例行公事、存檔清洗
  ui.js            面板、表單、列表、番茄鐘、商店、回顧、設定
  parse.js         一行快速輸入的解析
  reminders.js     日程提醒與系統通知
  sync.js          雲端資料夾同步（File System Access API）
  audio.js         WebAudio 即時合成音效（不需音檔）
  theme.js         色票、XP 數值、等級解鎖表
  data/            成就、もち台詞、商店品項、花の図鑑、每日任務題庫、好感度與衣裝
  scene/
    world.js       渲染器、鏡頭、後製 bloom、點擊拾取、省電降幀
    sky.js         依時間變化的天空、日月光、星星、雲海
    island.js      浮島、池塘與錦鯉、小徑、草叢
    decor.js       等級解鎖的裝飾
    garden.js      任務花圃
    towers.js      專案塔
    timeRing.js    時之環（日程）
    mochi.js       吉祥物もち
    cabin.js       もち的小木屋（專注時亮燈、冒煙）
    room.js        小木屋室內場景與切換
    particles.js   櫻花瓣、螢火蟲、爆花、煙火、天燈
    labels.js      釘在 3D 座標上的 HTML 標籤
    season.js      四季色票
    placed.js      商店擺飾的模型、放置預覽、縮圖
    outfits.js     もち的衣裝
    models/        細緻模型：雲鯨、星之大樹、小木屋與室內
public/
  sw.js            Service Worker（離線快取、通知點擊）
  manifest.webmanifest
tests/             Vitest 單元測試
```
