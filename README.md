# ひより日和 · 日程小島

用 three.js 打造的遊戲化日程／生活管理 App。你的一天是一座漂浮在雲海上的小島，風格走日系清透路線。島上住著兩位貓娘：活潑、照顧花圃的もち，和沉穩、幫你看時間與日程的ふじ，她們陪你一起努力、一起成長。

**線上玩：<https://ragorothers-alt.github.io/hiyori-island/>**（推上 `main` 就會自動跑單元測試和瀏覽器端對端測試、建置並發布到 GitHub Pages；開 PR 時也會跑，但不發布）

```bash
npm install
npm run dev      # http://localhost:5199
npm run build    # 輸出到 dist/
npm test         # 單元測試（Vitest）
npm run test:e2e # 瀏覽器端對端測試：離線、自動更新、教練、專案搜尋、平板的專案任務欄、番茄鐘和專注頁的貓（Playwright；第一次先跑 npx playwright install chromium）
```

## 玩法

| 你做的事 | 小島上發生的事 |
| --- | --- |
| 新增任務 | 花圃長出一株花苞（顏色＝分類，大小＝優先度） |
| 完成任務 | 花苞綻放，もち跳過去慶祝、ふじ在旁邊加油，獲得 XP |
| 一天的任務全部完成（≥3 個） | 「完美的一天」＋40 XP、花圃放煙火 |
| 新增日程 | 小島外圈「時之環」亮起一段光帶（0 點在後、12 點在前，光點是現在時刻） |
| 建立專案 | 專案町的一塊空地打好地基，完工的樣子淡淡浮在工地上 |
| 完成里程碑 | 房子再蓋一段（骨架 → 牆 → 屋頂）；全部完成時掛上暖簾和燈籠並施放煙火 |
| 番茄鐘（預設 25＋5 分） | もち和ふじ一起走回小木屋、一前一後鑽進門裡，畫面跟著進到屋內，全螢幕看兩人並肩坐在矮桌前（面板自動收起、其他資訊卡淡出，只留 Dock 上的計時器，出來後面板回到原本的樣子），もち讀書、ふじ寫筆記陪你；結束時伸個懶腰、開門出來擊掌，屋頂升起一盞天燈 |
| 升級 | 解鎖島上的新風景：石燈籠、鳥居、太鼓橋、繡球花、小祠、漂浮燈籠、浮空小島… |
| 最佳化時程 | ふじ幫你把還沒排的任務放進今天的空檔，避開睡眠、三餐和日程 |
| 習慣打卡、全部完成 | もち替你拍手；今天的習慣全做完兩人一起慶祝 |
| 戒除滿 1／3／7／14／30… 天 | 兩人慶祝這個里程碑；破戒了ふじ會安慰你，重新起算就好 |
| 各功能用得越來越多 | 小島周圍浮出「ひより町」的街區浮島，拱橋接回主島，店一路從小攤長成地標，店長也搬進來 |

另外還有每日任務（左下角，可領 XP）、連續打卡天數、51 枚成就印章、最近七天紀錄。天空會依真實時間從清晨、白天、黃昏一路變成星空夜晚，介面也會跟著換成夜間玻璃。

### 遊戲性

- **今日の本命**：按任務旁的 ☆（或快速輸入打 `★`、`!本命`）挑出每天最重要的 3 件，完成雙倍 XP，三件全清再 +30 XP（中途換掉、重新選的本命也算；本命搬到已經有 3 件本命的日子時，搬過去的那件就不再是本命）；花苞上會飄一顆小金星。一天完成超過 8 件後，任務 XP 減半——鼓勵休息，也讓灌任務刷分不划算
- **花の図鑑**：每完成一個任務就開出一朵花，共 26 種，分常見／少見／稀有／傳說。開什麼花看分類、時段、季節、是否本命、有沒有專注過、連續天數……本命任務的稀有機率加倍。紀錄頁可以看圖鑑與未發現花的線索
- **輪替的每日任務**：每天從 18 個題庫依日期抽 3 個（簡單／普通／挑戰各一），不會抽到當天做不到的
- **每週挑戰**：每週一個較大的目標，達成可拿每週限定擺飾（共 6 件，第一件免費）
- **逾期的花會垂下**：最近 7 天沒完成的任務會出現在今天的花圃裡、低頭褪色；完成或移到今天就慢慢挺回來（不扣 XP）
- **お守り**：在商店用金平糖買，漏掉一天時自動保住連續天數，最多帶 2 個
- **等級延伸到 30**：每兩級擴建一次小島——大櫻花樹、島緣瀑布、夜櫻雪洞、茶屋浮島、神社、紙鶴群、彩虹橋、賞月台、雲鯨、星之大樹；商店的擺飾也會依等級陸續上架，另有季節限定品
- **もちとふじの絆**：兩人共用一條好感度，摸摸、專注、回顧、清完本命、每天來看看她們都會累積。10 個等級解鎖 6 套衣裝（兩人各自換穿），還有新動作：もち偶爾去花圃澆水、專注時兩人的影子映在小木屋紙窗上陪你、ふじ每天送幾顆金平糖
- **專案町**：每個專案在小木屋後方的小鎮蓋一棟房子，照總平面排在町心廣場和街道兩旁、正面朝街。房子種類（町家、商店、工房、兩層旅館、茶屋，後方地標是望樓）依地塊和專案自動決定，屋頂、暖簾和小旗是專案色；里程碑完成的比例決定蓋到哪一段：地基 → 骨架 → 牆 → 屋頂 → 完工
- **小鎮會長大**：完成一個里程碑 +1 點、落成一個專案 +3 點，到 5／15／30／50／80／120／170 點升級，共 8 級，可用的地從 4 塊一路開到 30 塊。專案多到地不夠時，小鎮也會直接擴建到放得下（每個沒收藏的專案都有房子），而且不會縮回去。每升一級鏡頭飛過去，新街道一段段鋪出來，多一組街燈、行道樹、長椅和花台（Lv.1 有告示板、Lv.3 廣場出現噴水池、Lv.5 小鎮入口立起町門），等著的專案在新地上開工。紀錄頁的「專案町」顯示等級、地的使用量和升下一級還差幾點；舊存檔一打開就照累積的紀錄和專案數算好等級
- **小島會變大**：前 20 塊地用完、小鎮長到 Lv.7 時，島的半徑從 12 長到 14.3，外圈多出 10 塊地（西側、後方、東側）。過場一閃換成大島，時之環、ひより町的浮島與拱橋、茶屋浮島、雲鯨、星之大樹一起往外推，瀑布的溪流延長到新的島緣，賞月台也搬到新的島緣，鏡頭構圖自動拉遠
- **專案期限**：截止日可有可無，建好後也能在卡片上改或拿掉；在期限前落成額外 +60 XP，屋頂上方多兩圈金色光環；剩 2 天內的房子門口會亮紅燈籠
- **更多專案**：同時最多 30 個專案（不含收藏），每一個都在專案町有房子；分地的順序是進行中 → 暫停 → 已落成、早建立的先。收藏或刪除會把地空出來給下一個專案。已落成的房子留在鎮上，不常駐名牌；名牌重疊時快到期的優先，其他先淡出
- **專案狀態**：進行中／暫停／已落成。暫停的專案沒有到期提醒，房子的小旗降半旗、顏色變灰，名牌寫「暫停」；專案頁上方可以依狀態篩選，卡片上不常用的動作收在「更多」
- **最近動過的在前**：專案列表照最後一次動到它的時間排，最近的在最前面（不分狀態）。改名、換色、截止日、暫停、里程碑和細項、目標、進度、筆記、歸在它底下的任務（新增、完成、修改、刪除、寫任務紀錄），還有專注在它上面都算；換專案的任務兩邊都算。順序在進到專案分頁、或從詳情回到列表時才重排，待在列表上勾里程碑、改名時卡片不會在游標底下跳走；這時新建立或放回來的專案排在最前面。舊存檔照留下來的時間（最後一則進度、筆記、完成的里程碑和任務…）推回去排
- **快捷搜尋**：專案有 4 個以上時，列表上方出現搜尋框；從哪一頁按 `/` 或 `Ctrl`／`⌘`＋`K` 都會直接跳過來（正在看某個專案的詳情也會回到列表）。打字就篩，名稱、里程碑、細項、里程碑備註、目標、筆記、進度日誌都找；空白隔開的幾個字要在同一個專案裡都找得到，不分大小寫和全形半形，中文組字時選好字才找。名稱裡找到的排前面（整個名稱對上的最前面），找到的字會標出來；不是在名稱找到的，卡片上多一行寫在哪裡找到的那一段（例如「筆記　…圖書館的期刊…」）。搜尋時不管狀態篩選，收藏的專案也一起找、列在最後。`↑` `↓` 選、`Enter` 打開那個專案，`Esc` 先清掉字、再按一次離開搜尋框；選到的那個專案，島上房子的名牌也會放大。找不到時可以直接用打的字開一個新專案
- **專案詳情**（卡片上的「進度與筆記」，或點標題）：
  - **目標與統計**：名字、進度、目標和統計收在最上面一張小卡裡，畫面主要留給進度日誌和筆記。一句話寫下完成時的樣子；里程碑、細項、任務、專注和投入的時間排成一行；按「最近推進」展開最近 12 週每天有沒有推進的熱度格（這台裝置會記住展開或收起）
  - **進度日誌**：寫下這次推進了什麼，可以記花了多久、跟哪個里程碑有關、哪一天的事（能補記以前）；Ctrl＋Enter 送出。完成的里程碑、歸在專案的任務和專注的分鐘會自動排進同一條時間軸。每個專案每天第一則 +5 XP（一天最多算 3 個專案），寫了進度那棟房子會泛起一圈光
  - **筆記**：每個專案最多 100 篇，可以從會議紀錄、想法、階段回顧、清單的範本開始；支援 `#` 標題、`-` 清單、`1.` 編號、`- [ ]` 待辦（預覽裡直接打勾）、`**粗體**` 和網址連結。打字時自動儲存，可以釘選、搜尋
  - **里程碑細項**：每個里程碑可以拆成細項、加備註和自己的期限、上下調整順序；細項全勾完里程碑自動完成，沒做完時做了幾成也會讓房子多蓋一點
  - **里程碑期限提醒**：設了期限的里程碑，前一天ふじ提醒、當天もち也來打氣（提示卡寫著還差幾個細項，可開系統通知）；日程頁的重要日子倒數和日曆上也看得到，點小卡直接打開那個專案的里程碑。暫停、已落成、收藏的專案和做完的里程碑不提醒
  - **ふじ幫忙（接上 Claude 時）**：展開里程碑有「ふじ幫你拆細項」，列出 3～7 個建議，勾選想要的再加入（不會重複已經有的）；上方的「整理進度」讀日誌、里程碑、筆記和任務，寫出走到哪裡、最近完成、卡住的地方和接下來，可以存成一篇筆記（接下來的事變成能打勾的待辦）
  - **任務歸到專案**：詳情裡直接加，或新增任務時在輸入框旁的下拉選專案（選了會留著，接下來種的任務都歸過去，直到改回「不歸專案」；例行任務不歸專案）、在任務輸入框打「@專案名」（開頭幾個字就夠，優先於下拉）、編輯任務時選專案；這些任務用番茄鐘專注的時間會記進專案。刪掉專案時任務留著，只是不再歸屬；它寫過的進度日誌也從成就的累計則數扣回（跟刪掉一則日誌一樣）
  - **任務推進里程碑**：歸在專案的任務也算在某個里程碑底下，做完一件就和勾一個細項一樣，里程碑、專案的 % 和房子都跟著長（里程碑本身的勾還是最後一步，任務做完不會自己勾掉）。編輯任務時可以選算在哪個里程碑；沒選就是「自動」：還沒做的算下一個還沒完成的里程碑，做完的留在它完成那時正在進行的里程碑，之後里程碑一個個勾掉也不會跑掉。展開里程碑看得到底下的任務，可以直接打勾；任務列表上也標著它推進哪個里程碑。換專案、刪掉里程碑時改回自動；拆成三小步的任務也跟著原本的專案和里程碑
  - **長期任務**：專案裡要慢慢推進、沒有固定哪天做的事（例如「練習鋼琴」底下的每一首練習曲），新增時按「長期」，或編輯任務時打開「長期」。長期任務不排在哪一天：不出現在每天的任務、花圃和排程裡，不會逾期、不會跳卡關提醒，也不能當本命；只待在專案的任務清單裡，番茄鐘的目標也選得到它（時間記進專案）。完成那天才算那天的任務：開花、經驗值照常；取消完成又回到長期。移出專案或刪掉專案時變回一般任務，還沒做完的排在今天。子任務就當成它的階段（讀譜、分手練、合手、背譜、達到原速），全部勾完就完成
  - **速度**：練習曲可以記節拍器速度（♩＝每分鐘幾拍）。長期任務的任務頁上面有「♩ 速度」（這個專案已經有別件在記的話，一般任務也有）：填目標速度，練完按 ＋／− 照節拍器的刻度（40、42…60、63、66…120、126…208）調到今天練到的速度，也可以直接打數字（10～400）、按 Enter 存。還沒記過時按 ＋ 從目標的一半開始。旁邊寫著是目標的幾成、和上次比快了多少；練到目標變成「達標」，第一次練到這個目標時會說一聲（同一天降下來又按上去不再說，換了新目標練到再說）。一天記一筆：同一天再改就蓋過去，改回前一筆的速度或清空就當今天沒變；只動今天那一筆（時鐘往回調時比今天晚的紀錄照留）。換件、關掉前欄位裡打了還沒存的數字會先存，空白或看不懂的不算。每天的速度出現在任務頁和專案的進度時間軸上（例如「速度 ♩60 → 66」），也算進最近推進和熱度格、匯出的 Markdown；不給經驗值。按右邊的刪除可以不記（記過的要按兩下，一起刪掉）
  - **節拍器**：記速度的任務頁有「♪ 節拍器」，照現在記的速度打拍子（還沒記過就用目標的一半）；按 ＋／− 或改了數字，拍子跟著變；再按一次停，換件、關掉專案或分頁放到背景也會停。用瀏覽器的聲音排拍點（`src/metronome.js`），不受畫面忙不忙影響；手機開了靜音鍵時聽不到
  - **別的單位**：同一塊也能記別的會慢慢往上的數字。還沒記過時旁邊可以換單位：頁、章、公里、次、分鐘、％，或選「自己打…」取一個（最多 4 個字，例如「小節」）；記過就不能換（要換先刪掉再開）。別的單位可以有一位小數（0.1～99999），＋／− 一次 1，清單上是「32／200 頁」，時間軸是「32 → 45 頁」；新開的先跟這個專案最常用的單位一樣
  - **好久沒碰的提醒**：長期任務不會逾期，放久了沒人提醒。進行中的專案裡超過 7 天沒推進的長期任務（推進＝勾子任務、寫紀錄、記數字、專注在它上面），專案的清單上標「N 天沒碰」，今日總覽的前三要務下面列出最久的三件（點名稱打開、▶ 專注、「晚點」過一週再提醒），任務頁上方沒有卡關小卡時也提一件，ふじ一天說一次。跟卡關提醒共用設定裡的開關；暫停、收藏、落成的專案不提醒
  - **任務範本**：任務有子任務或在記數字時，任務頁下面有「存成範本」：取個名字（例如「練習曲」，同名的蓋過去，最多 20 個），把長期、分類、子任務和記什麼數字存起來。新增任務的地方每個範本一顆按鈕，點了下面會寫出這組設定，照著建；要刪按旁邊的「刪除範本」（兩下）。跟「沿用 N 個子任務」一次只用一個
  - **任務清單**：每件任務一眼看得到做到哪一步：子任務的小格子和「下一步：…」、日期（長期的寫「長期」）、速度（「♩66／120」，練到目標是「♩120 達標」）、專注了幾輪、紀錄記下的投入時間、最近一則紀錄是哪天、推進哪個里程碑。順序是逾期和今天的在前、長期的接著（照建立的順序）、之後日子的最後。新增時沒選範本就跟著這個專案最近那件任務：是不是長期、分類、有沒有在記數字（和單位）都一樣；按「沿用 N 個子任務」會把最近那件有子任務的整組帶過來（下面會列出是哪幾個），一首一首加練習曲很快
  - **任務頁**：點專案裡的任務（任務列表、展開的里程碑、進度時間軸上的任務標籤），或任務分頁上那件任務的專案標籤，就打開它自己的頁面。上面是完成的勾、日期（長期的標「長期」）、時段、預估、分類、推進的里程碑和建立日期，可以寫一段**說明**（要做到什麼程度、要注意的事，最多 500 字），說明下面是**子任務**（跟任務分頁上的是同一份，兩個以上時上面有一排格子）；再下面寫這件任務的**紀錄**：做了什麼、花了多久、哪一天，跟進度日誌一樣能改、能刪、Ctrl＋Enter 送出，時間軸上還有建立和完成這件任務。任務的紀錄就是專案的進度日誌、多記是哪件任務：專案的時間軸看得到（標著任務名，點了回到任務頁），也算進專案的投入時間、熱度格、匯出和經驗值。任務換到別的專案時紀錄跟著搬；只是移出專案或刪掉任務時，紀錄留在原本的專案裡當進度。上面的「♩ 速度」（長期任務，見上面的「速度」）、「◷ 專注」（今天的任務和長期任務）、「編輯」、「移出專案」（要按兩下）；Esc 或左上角回到專案，捲動位置和打到一半的字都還在
  - **匯出**：整個專案（目標、里程碑、任務和說明、筆記、進度日誌）存成一份 Markdown 檔
  - **平板和電腦的版面**：寬的時候（平板橫放、電腦）左邊切換進度／筆記，右欄上面切換「里程碑／任務」，各自佔一整欄（每個專案上次看哪一個，這台裝置記得）。點一件任務，任務頁開在左邊、右邊的任務清單留著，正在看的那件標出來，直接點下一件就換過去；清單很長時自己捲動、黏在畫面上，任務頁捲下去也還在。平板直放時平常照手機的四個分頁，打開任務頁時一樣左右兩欄；手機上任務頁疊在專案上面。Esc 回到專案列表（在任務頁時先回到專案）
- **上週回顧卡**：每週一第一次打開時，回顧上週的開花數、專注、本命、心情與新發現的花
- **ひより町**：小島會慢慢長成一座小鎮。六間店各綁一個功能，依那個功能的累積用量從 1 階長到 5 階：花屋（完成任務）、圖書館（專注分鐘）、時計台（完成日程＋套用排程）、錢湯（習慣打卡＋忍住）、喫茶店（生活記錄＋記睡眠）、郵便局（每日回顧）。第一次用到就有一座浮島從雲海升起、拱橋越過時之環鋪回主島；每次升階鏡頭會飛過去看新模樣。長到 2 階時店長搬進來——狸貓ぽこ、貓頭鷹ほうすけ、松鼠くるみ、水豚ゆず、兔子しらたま、狐狸こん——平常在自己的浮島上閒晃，點一下會打招呼，偶爾走過橋到主島找もち和ふじ聊天；你用到他們那間店的功能時也會說上一句。街區越多，預設視角往後拉一點。紀錄頁的「ひより町」列出每間店的階段、下一階還差多少和住在那裡的居民，點卡片可以飛過去。舊存檔一打開就照累積的紀錄蓋好，不必重新累積

### 日程與生活

- **時段安排**：日程分頁上方是一週的日期條，下面是一天的時間軸。日程和排進時段的任務都是可以拖曳的區塊：拖動改時間、拖下緣改長度，點一下編輯（日期、時間、顏色、備註、優先度、分類、預估時間）；點空白處新增日程。時間重疊的會標紅框。手機上長按一下再拖。任務做完就離開時間軸（今日總覽的今日行程也一樣），那段時間空出來給別的事；取消完成會回到原本的時段。日程（會議、約會）做完了照樣留著
- **整天的日程**：沒有時段的事（朋友來玩、旅行、出差）按新增日程旁的「整天」，可以選到哪一天（最多 31 天，不能設成例行公事）。它排在日程頁時間軸上方的一排小卡（跨好幾天的寫「第 2／3 天」），今日總覽的今日行程、日曆的月格（實心色條）、週檢視的摘要列和日詳情都看得到；點一下編輯，也能在編輯視窗切回有時段的日程。它不佔時段：最佳化時程、ふじ的排程、空檔和「現在」都不會把它算成一整天的忙碌。前一天和當天早上ふじ會提醒（剛加上的不會馬上提醒）
- **最佳化時程**：把還沒排的任務自動放進空檔，先預覽（虛線）再套用。順序是本命 → 高優先 → 逾期越久越前；重要的放在你精神最好的時段、低優先避開，工作與學習放進工作時段；行程之間留緩衝。今天會從現在開始排，塞不下的會告訴你。還沒排的任務列在時間軸上方，點一下放進最近的空檔，也可以拖到時間軸上
- **ふじ的排程教練**（分頁「教練」）：ふじ用問卷幫你規劃一天或一週，全部點選標籤——要排哪段（今天／這週剩下的天／下週一整週；從任務頁空白那天按「讓ふじ排這天」就是那一天）、想主攻哪些（分類、進行中的專案、自己加的項目如數學、英文單字）、什麼時候有空（平日早上、午休、下班後、平日晚上、睡前、週末上午／下午／晚上，照作息換算成實際時間）、最近有沒有考試或截止日、這週想做到幾天（輕量 3／穩定 5／全力 7）、每次多久（25／50／90 分）。送出後ふじ先給預覽：哪幾天、幾點、做什麼（例如「19:30 數學・練習題 50 分」），避開三餐、日程和已排的任務；考前 2～3 天排模擬練習、前一天總複習、當天只排 15 分鐘看重點（專案的截止日只影響那個專案）。可以「換個排法」再看一個，滿意就套用成真的任務（套用時照現在再檢查一次：已經過去的時段、跟預覽後才加的日程或任務撞到的算放不下，ふじ照實說建了幾段）；套用後也能整批撤銷（做完的留著），右上角的時鐘列出最近 10 次排程。下面的輸入框也能直接打「這週的數學複習 3小時」「明天排英文和物理 30分鐘」。沒接 Claude 時用本機規則排；接上之後交給 Claude 排（預覽右上角標「✦ Claude」），送出去的是你選的時段裡扣掉三餐、日程和已排任務之後的空檔，排回來的每一段都會再檢查一次（整段要在空檔裡、彼此留緩衝、項目是你選的），不合格的算放不下；Claude 沒回或一段都放不進去，就自動改用本機規則，ふじ會說一聲
- **週報**（「教練」分頁的第二頁）：
  - 本週到目前：完成率、投入時數、完成番茄、連續天數；有在用的日子少於 3 天時先顯示「第一份週報準備中」
  - 本週表現分析：完成率圓環，加上完成／沒完成的件數、本命、專注分鐘、習慣達成率，跟上週同一段（星期一到同一個星期幾）比較 ↑↓
  - 專案這週：這週有動靜的專案（最多 6 個），投入和專注的時間、寫了幾則進度、完成幾件任務和里程碑；記數字的任務這週從多少到多少（例如 ♩60 → 72、+12），還有這週完全沒碰的長期任務。點專案名稱打開它
  - 習慣洞察：最常完成任務的時段（從完成時間算，舊資料也能用）、最常專注的時段、哪一天最有效率、最穩和常漏掉的習慣、常被往後挪的任務；資料不到 5 天時依作息推測。精神時段跟實際不一樣時，可以一鍵改掉
  - ふじ的週報洞察（接上 Claude 時）：按一下，ふじ讀這週和上週同一段的數字、習慣洞察，寫一句標題、跟上週比的觀察和 1～3 個下週可以試的小調整；每週存一份在這台裝置，想用新的數字再看一次再按
  - 記憶圖鑑：每週一張卡（完成率、番茄、心情色點），往回 12 週；點卡片打開那一週的回顧卡
- **重要日子**：日程頁新增日程表單下面一排倒數小卡（考試、截止、紀念），進行中專案的截止日和里程碑期限也會列進來；剩 3 天內變紅，日曆上那天有記號。前一天和當天第一次打開時ふじ會提醒
- **卡關提醒**：任務往後挪了 2 次以上、或逾期 3 天以上時，任務頁上方出現一張小卡（一次一件），ふじ問你要不要拆小：拆成三小步（先開個頭、推進一半、收尾，時間照原本的預估分配，本命留在第一步）、排進明天、先放下，或不再提醒這件。設定裡可以關掉
- **作息**：設定起床、就寢、三餐（可增減）、工作／上課時段、精神最好的時段與緩衝時間；時間軸上會畫出睡眠、用餐與工作的色帶，排程也會避開。就寢在午夜後（例如 01:00）時，午夜到就寢那段也算醒著，ふじ排得進去，「睡前一小時」也照實際的就寢時間算（就寢 00:30 時是 23:30–00:30）。早上會有一張「昨晚睡得好嗎」的小卡記錄睡眠，就寢前 30 分鐘ふじ提醒你準備睡覺
- **習慣**（新分頁）：養成習慣可以設每天幾次（例如喝水 8 杯）和星期幾要做，有連續天數、30 天達成率與 12 週熱度圖，熱度圖上也能補打卡（剛開始記的習慣也能補之前幾天）；戒除習慣用數日子的方式，想做卻忍下來時按一下「忍住了」，破戒了也只是重新起算，不扣分。有常見習慣的範本可以一鍵加入
- **日曆**：點上方的日期、Dock 的日曆按鈕或按 `C` 打開。月檢視每天標出日程、任務完成度、習慣、心情、生活記錄；週檢視用時間格看整週的日程與排好的任務。點一天看詳情，可以直接跳到那天或打開編輯
- **警語**：在紀錄分頁最上方，寫幾句提醒自己的話（最多 30 句，點字就能改，暫時不想看的可以先收著）。面板最上面輪流放一句（每 15 分鐘換一句，› 換下一句、× 今天先收起來），醒著的時候（作息的起床到就寢）每隔 30 分～3 小時もち或ふじ念一句，專注中不打擾；也可以只放在面板上不定時提醒
- **生活記錄**：在紀錄分頁的警語下面，隨手記下飲食、運動、心情、花費、休息或筆記，當天變成一條時間軸，也能記今天的精神；下面有最近 7 天的睡眠統計（平均睡眠、就寢與起床時間、規律度）和花費
- **訂閱**：在紀錄分頁的生活記錄下面，記下每個訂閱服務的價格、週期（每 N 週／月／年）、扣款日、分類和付款方式（只寫「信用卡」這種名稱，看起來像卡號會被擋下）。上方算好每月與一年大約花多少、這個月還要付多少和各分類的比例；「接下來 30 天的扣款」依日期排好。扣款前 0／1／3／7 天ふじ會提醒，免費試用結束前也會提醒（同一次扣款只提醒一次）。外幣照可以自己改的匯率換成新台幣；取消後到期前照樣列著，還沒到期可以反悔照原本日子繼續，停掉的也能重新訂閱，以前付過的錢會留著。日曆上扣款日標「払」，點了直接打開那個訂閱
- **快速輸入的預估時間**：任務打 `寫報告 1.5小時`、`回信 20分鐘` 會記成預估時間，排時段時就照這個長度

### 其他功能

- **子任務**：任務列表上按任務右邊的「拆成子任務」，直接打字、按 Enter 一個個加進去（最多 30 個）。有子任務的任務下面會列出來，可以勾、點名稱改名、刪除；任務名稱下方標著做了幾個（例如 1/3），點一下收起或展開（還有沒做完的會自動展開）。跟里程碑的細項一樣：最後一個勾完時任務跟著完成（經驗值、開花照常，子任務本身不給經驗值），完成後又取消其中一個，任務回到未完成；直接勾掉任務的話子任務維持原樣。專案的任務頁、今日總覽的前三要務、日曆的日詳情和專案匯出的 Markdown 也看得到；拆成三小步時子任務交給第一步
- **一行快速輸入**：在任務欄直接打 `明天下午3點到5點 設計週會 #工作 !高`，下方會即時預覽解析結果；有時間的會變成日程，沒有的變成任務。支援 今天／明天／後天、`下週三`、`5天後`、`11/3`、`2027-02-03`、`晚上8點半`、`14:00-15:30`、`9am`、`30分鐘`、`2小時`、`每天`／`平日`／`每週一三五`、`#分類`、`!高` 或 `!!!`。`晚上12點`、`今晚12點半` 是半夜（排到隔天 00:00、00:30），`晚上11點到12點` 排到 23:59 為止。整天的日程打 `11/17 朋友來玩 整天`（也認 `全天`、`整日`），好幾天打 `11/17到11/19 旅行` 或 `11/17-19 旅行`；寫了時間就還是有時段的日程
- **例行公事**：任務和日程都可以設成每天、平日或每週幾。每天自動長出當天的那一份；刪掉某一天的不會再長回來
- **提醒**：日程和排進時段的任務在開始前 0／5／10／15／30 分鐘提醒（ふじ提醒你、提示卡、音效），就寢前 30 分鐘也會提醒（就寢在午夜後也對得上）；重要日子、里程碑期限和整天的日程在前一天和當天提醒，可開啟系統通知。電腦睡著、分頁被凍結而錯過的，醒來時已經開始 15 分鐘以內的還會補提醒；同時開兩個分頁也只響一次
- **快速記錄**：Dock 的「＋」或鍵盤 `N`，在任何分頁叫出一張卡（不用先換到任務頁，今日總覽的「種下一件」也是開它）。一行字、Enter 記下，輸入框留著接著記下一件；寫法跟任務頁那一行一樣（「明天 15:00 開會」是日程、「每天」「!高」「#生活」「@專案」都認得），沒寫日期就加在今天，分類用下面那一排選。切到「生活記錄」可以記一筆飲食、運動、心情、花費、休息或筆記（花費會把字裡的金額拿出來：「午餐 120」）。剛記的幾筆列在下面，記錯了按「復原」；Esc 或點旁邊關掉。裝到主畫面後長按圖示有「快速記錄」捷徑（網址帶 `?add`），打開就能打字
- **檢視進度**：今日總覽的「今日進度」底下有這週七天的小長條（淡的是那天排了幾件、實心是做完的，今天那根亮起來），「看週報」直接到教練的週報。紀錄頁最上面有一排跳轉（設定、生活記錄、睡眠、訂閱、統計、最近七天、圖鑑…），捲動時黏在上面。每個分頁各自記住捲到哪裡，再點一次目前的分頁回到最上面
- **打開時的今日摘要**：每天第一次打開（或開著過了一天、回到 App 時），貓咪從旁邊小跑步進來坐下，用一張對話卡說今天的事：幾件任務、幾個日程，下一個日程還有多久、整天的日程、先做的三件任務（本命、重要、時間早的在前）、還沒打卡的習慣；再列該留意的：逾期的任務、三天內的重要日子／里程碑／專案截止、快扣款的訂閱、一直往後挪的任務、好久沒碰的長期任務。離開半小時以上再回來時，最前面多一段「你不在的時候」（寫著離開了多久）：上次看 App 之後開始、現在已經結束的日程（App 沒開著時提醒不到；最多回頭看三天）、這段時間扣了款的訂閱、昨天傍晚前就離開的話再加上昨天沒打卡的習慣。「上次看 App」是這台裝置自己記的（每分鐘和離開分頁時記一次）。點一項直接跳到那一頁（或那個專案、那件任務），「▶ 專注第一件」打開專注設定，「知道了」、Esc 或點旁邊關掉，貓自己走出去。貓是專注頁那一隻（每天換毛色），點牠會喵。正在專注、有別的視窗開著時不出來；一週回顧和晚間回顧等摘要關掉才出現。這台裝置一天只自己出來一次，設定裡可以關、也可以「現在看」；系統開了減少動態效果時貓直接坐著、字一次出來
- **到點了還沒做完、做完了還想繼續**：倒數的專注到點、進入休息後，全螢幕計時、點時間打開的小視窗和到點的提示卡上都有「還沒做完，延長」：休息取消，從到點那一刻接著往上數（加時；到點超過一小時才回來就從現在開始數），做完按「做完了」把多做的分鐘記進去——只加專注的分鐘，不多算一顆番茄，不到 1 分鐘不另外記；之後再休息、照原本的輪數接下去（加時最長也是 3 小時）。最後一輪的休息中有「再加一輪」（休息完自動開始，最多加到 12 輪）；最後的休息也結束時，提示卡上的「再來一輪」照剛才的長度和目標直接開始。正向計時是自己按做完的，休息時沒有「延長」
- **專注到點的通知**：開了系統通知之後，番茄鐘的專注結束、休息結束都會通知（正看著 App 時只有畫面上的提示和音效）。**手機鎖著螢幕、切到別的 App 也收得到**：開始計時時，App 把「這台裝置的推播網址」和「幾毫秒後到點」交給自己的 Cloudflare Worker，到點由它推一則過來；推播本身沒有內容，通知上的字（任務名稱、第幾輪）留在裝置上，由 Service Worker 顯示。暫停、停掉、換長度都會跟著重排或取消（開了好幾個分頁也一樣）；排的時候剛好沒網路，連上線或回到 App 時會補排；到點時裝置離線超過 10 分鐘就不補送。同一次到點只響一次：伺服器排上了就交給它，頁面醒著的話等幾秒還沒來才自己發。日程頁的提醒那一列有「試一則」：10 秒後傳一則，可以鎖上螢幕試；下面一行寫著上一則到點通知是幾點送到這台的（到點沒看到通知時，看它就知道是沒送到、還是送到了）。推播到的時候正看著 App，通知幾秒後自己收掉（畫面上已經有提示）：「正看著」是 Service Worker 直接問頁面、頁面自己回答，不照瀏覽器回報的狀態——手機鎖著時頁面被凍住，有的 Android 瀏覽器還留著鎖螢幕前「正在看」的樣子，照它收的話通知會在螢幕暗著時就不見。Worker 的紀錄（`npx wrangler@4 tail`）記著每一則排上、取消、送出和推播服務回了什麼（只記推播服務的網域）。
  - iPhone／iPad 要先在 Safari「分享 → 加入主畫面」，從主畫面打開後再開啟系統通知（iOS 16.4 以上；Safari 分頁裡沒有通知功能）
  - 手機整段時間都鎖著時，收得到的是「專注結束」那一則：休息要等回到 App 才開始算（免得人不在時自己接著跑下一輪），所以休息結束、下一輪的通知是回來過之後才有
  - iPhone 的「即時動態」（鎖定畫面和動態島上即時倒數）做不到：那是原生 App 才有的功能（ActivityKit），網頁 App 沒有對應的 API。能做到的是到點那一刻的通知
- **拖曳時之環**：直接拖光帶就能改時間，拖兩端可以改長度
- **四季**：依日期換成春櫻、夏綠、秋楓、冬雪，花圃、樹冠、飄落粒子、兩人的髮飾和圍巾都會換季
- **金平糖商店**：完成任務會同時拿到金平糖（約 XP 的五分之一），可以買 35 種擺飾放在島上任何空地；點擺飾可以移動或收回（退一半）
- **專注完接著記**：專注的是專案裡的任務時，結束的通知上有「寫紀錄」，按了打開那件任務的頁面、游標在紀錄的框裡（時間已經記成專注，紀錄的「花了」不重複填）
- **專注的目標**：點番茄鐘上的標籤（手機上在計時設定的「目標」下拉）選今天的一件任務、專案裡的一件長期任務，或直接選一個專案。選任務時那朵花外圈會亮起金環，每完成一輪就長大一點；選專案時專注的分鐘記進那個專案（專案頁的時間軸和統計看得到），做完那棟房子泛起一圈光。專案頁上方的「◷ 專注」可以直接開始；歸在專案的任務本來就會把時間記進專案，不會重複記
- **計時方式與長度**：沒在計時時點 Dock 上的時間，先選「倒數計時」或「正向計時」。倒數用刻度尺選 10～90 分，也能設連續 2～4 輪（休息完自動開始下一輪）；正向計時從 0 開始往上數，做完按 ■（或全螢幕的「做完了」），滿 5 分鐘就照實際分鐘記下來，最長 3 小時。休息 5／10／15 分兩種都能設。XP 依長度給：25 分是原本的份量，短的少一點、長的最多兩倍。每次專注會記下落在早上、下午、晚上還是深夜。計時中關掉分頁也會接著算；但那一段結束一個多小時後才回來的（例如晚上開始後關掉，隔天才打開），不確定那段時間在不在專注，那一輪就不記，ふじ會說一聲
- **專注頁的貓咪**：App 模式開始專注時，計時圈下面那片地板會有一隻小貓從旁邊走進來散步：走走停停、坐著東張西望、舔前腳洗臉、伸懶腰，偶爾散步出畫面再回來。專注越久越睏，十幾分鐘後多半趴下來蜷著睡、冒出小小的 z；暫停時醒來坐著看你，休息時先伸個懶腰，接著比較好動，會蹲低扭屁股往前撲。點牠會「にゃ」一聲回頭看你，三秒內點三下會呼嚕呼嚕冒愛心；電腦上滑鼠移過去，牠會停下來看你。每天換一隻（三花貓、橘貓、虎斑貓、黑貓、白貓、賓士貓），夜裡換成亮色的外框。右上角的腳印可以請牠離開（小跑步出畫面），再點一下又走回來，設定會記住；系統開了「減少動態效果」時，牠只在角落睡覺、不走動。貓是 SVG 畫的，身體、腳和尾巴每一格照 `src/catWalk.js` 算出來的姿勢重畫，沒有圖檔；只在專注頁開著時動，睡著時一秒只畫 15 次
- **晚間回顧**：晚上 9 點後邀請你用天氣（晴／虹／星／曇／雨）記下今天的心情和幾句話（最多 500 字，Enter 記下、Shift＋Enter 換行），紀錄頁會變成小日記，日曆上也看得到每天的心情。今日總覽的「今日反思」就是同一篇，白天先寫了晚上就不會再問
- **夜間模式**：Dock 上的月亮／太陽鈕（或 `D`）一鍵切換白天和夜晚，切換時天空會快轉一段夕陽或日出；「紀錄 → 設定 → 夜間模式」可以選依時間（預設，傍晚自然變暗）、跟著系統深色模式、一直白天或一直夜晚。夜晚時面板換成深色，島上的燈籠、小木屋窗燈和螢火蟲都會亮
- **省電模式**：閒置時把畫面更新率降到 30／15 fps，有動畫或操作時立刻回到全速。不管有沒有開，全螢幕編輯或 App 模式蓋住小島、或切到別的分頁時，小島都停止繪製（只留每 0.5 秒一次的時間推進，視窗大小變了之類要補畫時才單獨畫一幀）。顯示卡被系統收走（例如 iPhone 切到背景太久）時，回來會自動接上；一直沒還回來就請你重新整理
- **畫質**：自動（依裝置挑）、高（解析度上限 1.5 倍、反鋸齒、白天也有柔光、陰影 2048）、標準（1.25 倍、陰影 1024，筆電和手機比較省）
- **安裝成 App（PWA）**：正式版可以安裝到桌面或手機主畫面，離線也能打開。小島（three.js、場景和兩人的模型）載入過一次就會留在快取裡；一直用 App 模式、從沒切回小島的裝置，第一次切回小島時要連網。開著時部署了新版：舊頁面要載入的畫面已經換掉時，會自動重新整理一次換成新版（30 秒內只試一次）。離線快取的版本由每個檔案的內容算出來，只改首頁、manifest 或圖示也會換新
- **保留資料**：請瀏覽器在空間吃緊時不要清掉這個網站的資料。Chrome 系和安裝成 App 時開機就請（不會跳出詢問）；Safari 一般分頁、Firefox 等第一次改到自己的資料時才請一次（Firefox 會問你要不要允許）

## 操作

- 拖曳旋轉、滾輪縮放；點花／專案町的房子／時之環上的光帶，可以跳到對應的清單項目
- 點もち或ふじ可以摸摸她們，偶爾另一位也會想被摸
- 清單裡點任務標題，鏡頭會飛到那朵花；點優先度或分類標籤可以直接切換
- 全螢幕編輯：按分頁列右邊的展開鈕（或 `E`），面板會撐滿整個畫面，寬螢幕時排成左右兩欄（日程頁的時間軸會拉長到整個高度）；再按一次或 `Esc` 回到小島。開始專注、開商店、回到全景時會自動離開
- **App 模式**：按 Dock 上的手機鈕，或「紀錄 → 設定 → 介面」選 App，就能像一般 App 一樣用：小島停下來藏到後面，面板撐滿整個畫面，問候、等級和連續天數放在最上面。分頁列和側欄照 iOS 27 的 Liquid Glass 做（參考 Apple 的 iOS 27 UI Kit）：浮起來的毛玻璃、選到的那一格墊灰色膠囊、圖示染上櫻花粉。玻璃的透明度可以在「紀錄 → 設定 → Liquid Glass」用滑桿調（跟 iOS 一樣，往左清透、看得到後面的內容，往右底色更實、字更清楚），上面有即時預覽；小島模式的面板、等級卡、日期列、Dock、每日任務，和兩種模式的小視窗、提示卡、對話框也都跟著變。App 模式的底是淡淡的粉、藍、紫光暈，側欄後面有東西，調了才看得出差別。卡片也照 iOS 27 的分組列表：實心的白卡片（夜晚是比底色亮一階的靛紫）、圓角 26、沒有框線和陰影，卡片裡的小項目改用淡灰色的底；任務列表變成一整張卡片、一列一列用細線隔開，本命在左邊一道金色。手機上分頁列是浮在最下面的玻璃膠囊（內容從底下捲過去），番茄鐘縮成它上方右邊的小膠囊；電腦上改成浮在左邊的玻璃側欄（任務和習慣旁標著今天還剩幾件），內容上方是頁名和日期，寬螢幕時問候、經驗值和番茄鐘也收進側欄（問候右邊的鈕可以把側欄收成只有圖示的窄欄、內容區變寬，再按一次展開；每台裝置分開記），中等寬度只留圖示、番茄鐘浮在內容下方；開始專注時整個畫面變成大計時器（左上角縮小，計時照走，點膠囊上的時間再打開），也可以按「到小木屋看兩人陪你讀書」切回小島。もち和ふじ說的話會出現在下方的小對話框。要回小島，按分頁列最後的「小島」（或 `V`）；開商店也會自動切回小島。這個選擇每台裝置分開記，例如手機用 App、電腦看小島。App 模式開機時不載入小島（不下載 three.js 和兩人的模型），介面一下就出來；第一次切回小島時才下載、建好（通知的位置會顯示「小島準備中」，這段時間可以照常用，改變主意切回 App 也不會被拉走），之後切換都是立刻的
- **今日總覽**（第一個分頁「總覽」，小島模式和 App 模式都有；打開 App 模式時先看這一頁，小島模式照舊從任務開始）：一頁看完今天——上面是日期、ふじ依今天狀態說的一句話和富士山插畫（夜間換成月夜版）；下面最先是「**現在**」：大大的時鐘（對齊整分跳動）、現在在作息的哪一段（精神最好的時段、午後、睡前一小時、過了就寢…）、距離就寢還有多久、扣掉三餐、行程和已排的任務（含緩衝）後還有多少空檔、還沒排時段的任務有幾件（放不下全部時會說），一條從現在到就寢的空檔條；正在做什麼（日程、三餐、排好的任務，到幾點）、眼前這段空檔有多長，一句這個時段適合做什麼，再列出放得下這段空檔的還沒排的任務（精神好的時候重要的先，午後輕的、短的先），可以直接 ▶ 專注或「排進 20:40」；也提醒還沒打卡的習慣。接著是今日進度圓環（已完成／進行中／待完成；排的時間到了或正在專注的算進行中）、今天的一句話、今日行程（日程和排進時段的任務照時間排，紅線標出現在，點一下編輯；任務旁的 ▶ 準備專注）、今日前三要務（今天的本命，不滿三件用重要的任務補位，按 ☆ 選成本命，可以直接勾完成；**點任務名稱就跳出專注設定**，目標已經選好，選倒數或正向、長度、輪數再按「開始專注」；前三件以外今天還沒做的收在下面的「其他今天的任務」，展開後一樣點名稱；正在專注的那件標著「專注中」，專注到一半點別件就換成那件）、每日任務和每週挑戰（做到了直接領取）、習慣養成（這週一到日，點今天那格就打卡），最後是**今日反思**：選今天的天氣、寫幾句話（做得好的、想改進的、明天想試的），按「記下來」或 Ctrl＋Enter；跟晚間回顧是同一篇，第一次記下 +10 XP，打到一半時畫面重畫（每分鐘、或在別處打勾）字和游標都留著，中文組字中不重畫。只看真正的今天，不跟著上方選的日期；開著的時候每分鐘更新一次。小島模式的側邊面板窄，卡片排成一欄；全螢幕編輯（`E`）時和 App 模式一樣排成三欄
- 鍵盤：`N` 快速記錄（在任務頁是跳到新增任務的那一行）、`/` 或 `Ctrl`／`⌘`＋`K` 搜尋專案、`E` 全螢幕編輯、`D` 切換白天／夜晚、`F` 開始／暫停專注、`V` 回到全景（在小木屋裡時回到小島，App 模式時切回小島）、`S` 開關商店、`C` 開關日曆、`←` `→` 切換日期、`1`–`7` 切換分頁、`Esc` 關閉（一次只關最上面那一層）。對話框、日曆或全螢幕計時開著時，快捷鍵先不作用；對話框打開時焦點會移進去，關掉後回到原本的按鈕。焦點在分頁上時，方向鍵是換分頁（`Home`／`End` 到第一頁和最後一頁）；習慣的熱度圖只佔一個 `Tab` 停點，進去後上下是前後一天、左右是前後一週；番茄鐘長度的刻度尺跟一般滑桿一樣，方向鍵一格、`Home`／`End` 到兩端。任務列表勾完成、改本命之後焦點留在同一列；改名到一半（包括中文組字中）時，同步拉回的新資料先不重畫那個列表。ふじ教練的問卷、作息、衣裝這些選項按鈕會報讀選了哪個。系統設定「減少動態效果」時，捲動不用平滑動畫，小島的鏡頭直接切過去、閒置時不自己轉、慶祝特效收小。任務、里程碑、子任務的勾選按鈕會念出是哪一件和有沒有完成；日程頁每分鐘更新時焦點留在原本那顆；桌面收起面板後 Tab 鍵不會跑進看不見的按鈕
- 放置擺飾時：移動滑鼠選位置、點一下放下、`R` 旋轉、`Esc` 取消

## 設定

在「紀錄 → 設定」：**介面**（小島／App，只改這台裝置）、夜間模式、省電模式、畫質、**字體大小**（小／標準／大／特大，放大面板、對話框和提示卡的字）、**卡關提醒**、**這一版的新功能**（依日期整理的更新紀錄，有沒看過的新版本時設定和「紀錄」分頁上有小紅點）、**意見回饋**（到 GitHub 開一則 issue，預先填好版本和畫面大小，不帶個人資料）、**ふじ的 AI**（見下面「接上 Claude」），以及下面的資料與同步。

## 接上 Claude（ふじ的 AI）

可以接上自己 Claude Console 的 API，讓ふじ用 Claude 排程、拆里程碑的細項、整理專案進度、寫週報洞察。API 金鑰**不會**放進網頁：它存在自己的 Cloudflare Worker（就是線上同步用的那一個）的 secret 裡；網頁只填一組自己想的通行碼，Worker 對得上才幫你呼叫 Claude。

1. 在 Claude Console（console.anthropic.com → API Keys）建立一把金鑰
2. 在 `worker/` 資料夾執行下面兩行，照提示貼上金鑰、再輸入一組自己想的通行碼（越長越好，中文也可以）：
   ```bash
   npx wrangler@4 secret put ANTHROPIC_API_KEY
   npx wrangler@4 secret put AI_PASS
   ```
3. 到「紀錄 → 設定 → ふじ的 AI」按「設定通行碼」，填同一組通行碼，按「儲存並測試」；看到「連上了」就好了。每台裝置各填一次（通行碼只存在那台裝置，不會同步、不會匯出）

設定裡可以選模型：Opus（預設，想得最周到）、Sonnet（快又穩）、Haiku（最快最省）。費用照你 Claude Console 的帳單計算；「測試連線」只查模型資料，不花 token。用到 AI 時，那一項需要的資料（例如排程的空檔、專案的日誌和筆記、這週的數字）會經過你的 Worker 送給 Claude。

Worker 端（`worker/src/ai.js`）：提示詞和回傳格式都寫在 Worker 裡，前端只送資料；回傳用 structured outputs 固定成 JSON（排程的日期和項目直接寫進 schema 的 enum）。Opus／Sonnet 開了伺服器端備援（`fallbacks: 'default'`，被安全機制擋下時換備援模型重跑；Haiku 沒有）。通行碼用雜湊比對，而且先驗通行碼才讀請求內容；每個 IP 每分鐘最多 10 次，請求最大 120 KB（邊讀邊算，超過就停）。錯誤會換成看得懂的話（通行碼不對、金鑰不能用、額度用完的原因、Claude 太忙…）。測試（`tests/ai.test.js`）把 Claude 的用戶端換成假的，檢查送出的參數和各種回應。

## 資料與同步

資料都存在瀏覽器的 localStorage。同一個瀏覽器開了兩個分頁時，一邊存檔，另一邊會馬上換成那一版，不會用舊資料把它蓋掉。存檔平常是改完就存；資料多到存一次要超過 8 毫秒時，連續的變更會合併成 0.4 秒存一次，關分頁、切到背景或同步之前一定先存完。在「紀錄 → 設定」可以：

- **匯出／匯入** JSON 備份：匯入前會把現在的小島留成備份（設定裡的「被取代的資料」可以還原），備份存不進去就不匯入；匯入的舊存檔停在好幾天前時，お守り和戒除里程碑會照樣結算
- **清除範例資料**：第一次打開時放的範例任務、日程和專案（id 開頭是 `ex-`）可以一鍵清掉，自己加的資料、經驗值和統計都不動；清完按鈕就會消失
- **重置小島**：清空成一座空島（不會再放範例），今天的每日任務照樣有；重置前的小島同樣留成備份，後悔可以還原。備份存不進去（空間滿了）時先不清，告訴你沒有備份，30 秒內再按一次才清；另一個分頁或雲端已經是新版的ひより時，舊分頁不能重置
- **線上同步**（手機、電腦都能用）：第一台按「開始同步」會拿到一組 28 碼（140 bits）的同步碼（以前開的 16 碼同步碼照樣能用）；其他裝置按「輸入同步碼」，或用手機相機掃設定裡的 QR code、打開「複製連結」的網址
  - 每次變更約 1.5 秒後上傳；回到視窗、恢復連線，或開著時每 30 秒會檢查別台裝置的新資料；手機切到背景前會先把還沒送出的變更送出去
  - 端對端加密：同步碼只留在裝置上，用它推導出給伺服器找資料的 id 和 AES-GCM 金鑰；上傳的是壓縮後加密的整份小島，伺服器看不到內容。同步碼就是鑰匙，弄丟了就只能重新開一組
  - 「停止同步」只讓這台忘記同步碼；「刪除雲端資料」會把雲端那份刪掉，其他裝置也會停止同步
  - iPhone 加到主畫面的 App 和 Safari 是分開的兩份資料：要同步主畫面的 App，請在 App 裡輸入同步碼
- **資料夾同步**（電腦版 Chrome／Edge）：選一個放在 OneDrive、Dropbox、Google 雲端硬碟同步資料夾裡的檔案，之後每次變更都會自動寫進去；回到視窗或每分鐘會檢查有沒有別台裝置的新資料。第一台按「建立同步檔」，其他電腦按「連結既有檔案」選同一個檔案。瀏覽器重開後可能要按一次「繼續同步」重新授權（瀏覽器的安全規定）。注意：這個檔案是**沒有加密**的 JSON，雲端硬碟的服務商和拿到檔案的人都看得到內容；要加密請用線上同步

兩種同步判斷新舊的規則相同（`src/sync.js`），也可以同時開：

- 只有一邊改過：自動用新的那一邊
- 兩邊都改過（例如兩台都在離線時用過），或已經有資料的裝置第一次連上：不會自動覆蓋，會請你選「用雲端的」或「用這台的」
- 被取代的那一份會留成備份，設定裡的「被取代的資料」列出最近 3 份（同步、匯入、重置、還原都算），各自可以「還原」；還原時現在的小島也會先留一份，還原錯了還能換回來。空間不夠時先丟最舊的

存檔出問題時：

- **存不進去**（多半是瀏覽器空間滿了）：先從最舊的開始丟「被取代的資料」備份，讓現在的小島存得進去；丟光了還是不行（備份會放回去），就跳出提示請你先匯出一份，之後又存得進去時再告訴你；這時同步不會把「上次同步到哪」往前推，重新打開後會再從雲端拉一次，不會拿舊存檔蓋掉雲端
- **讀不進來**（存檔壞掉、或清洗時出錯）：原文另外存在 `hiyori-rescue`，先換成範例島並提醒你；有開同步的話會從雲端拉回來，絕不會把範例島推上去蓋掉其他裝置（就算拉回來之前在範例島上加了東西，也是拿雲端的、加的留成備份）。原文存不下來時，在你自己改資料之前不會蓋掉它
- **新版 App 存的資料**（例如另一個分頁已經更新到新版、或雲端是新版寫的）：舊版的分頁不讀進來、也不拿舊格式蓋掉，同步和匯入先停下來，提醒你重新整理更新。存檔裡看不懂的欄位會原樣保留
- **單純多一個欄位的更新不用重新整理**：每一筆紀錄（任務、專案、里程碑、進度…）和最上層不認得的欄位，讀進來再存回去都原樣留著（太大的不留，擋匯入的檔案塞垃圾）。所以新版只是多記一個欄位時，還沒更新的裝置照常用、也不會把新欄位洗掉；只有舊版照舊的意思去用會出錯的改動，才會升存檔版本、請舊的裝置重新整理
- 往外寫的路（平常的上傳、切到背景前的送出、衝突時選「用這台的」）都先過同一道檢查（`SyncEngine._pushBlocked`）：舊分頁和讀不進來時的範例島都送不出去
- **日期倒退**（搭飛機往西飛、改了時區）：例行公事不會在同一天長出第二份（刪掉的也不會長回來），連續天數不會被歸零、每天第一次打開的好感度也不會多給一次

### 線上同步後端

`worker/` 是一個 Cloudflare Worker，資料存在 D1（SQLite）：每組同步碼一列，存 vault id 的 SHA-256、版本識別（每次修改都換一個的隨機字串，不用時間比新舊：各台時鐘可能不準）、修改時間和密文。上傳時要帶「我以為雲端現在是哪一版」，對不上代表別台剛寫過，伺服器回 409，前端重新比對，不會蓋掉別台的變更。測試（`tests/cloud.test.js`）用 Node 內建的 SQLite 跑真正的 Worker 程式，模擬兩台裝置互相同步。

防護：

- **寫入要驗證**：同步碼除了推導出 vault id 和加密金鑰，還推導一把 auth（三者互相推不出來）。寫入和刪除都要帶 auth，伺服器只存它的 SHA-256：只知道 vault id 的人讀得到密文，但不能寫入、回滾或刪除。舊的 vault（加上 auth 以前開的）第一次收到帶 auth 的寫入時記下來，之後不帶的（舊版網頁）寫不進去，重新整理更新就好。這個「第一次記下」只收到 2027-01-01（`LEGACY_UNTIL`，`[vars]` 可改）：舊同步碼在那之前同步過一次就自動升級；過了期限還沒記下的不再收寫入（資料還在裝置上，重新開一組同步碼就好），免得只知道 vault id 的人搶先登記。還沒記下 auth 的舊 vault 也不能只憑 id 刪除：按「刪除雲端資料」時前端先寫一次讓它記下這台的 auth，再刪
- **總量有上限**：每個 IP 每分鐘 5 次建立，整個伺服器一天最多建 300 個、資料庫總量 400 MB（可以用 `[vars]` 的 `CREATE_DAILY`、`MAX_TOTAL` 改）；建了一天以上還沒放資料的空 vault 會清掉。總量滿了時，新建立和會讓資料變大的寫入都擋下（回 507，變更先留在裝置上），變小或一樣大的照常同步。總量檢查和寫入是同一句 SQL，同時來好幾個寫入也不會一起超過上限
- **AI**：每個 IP 每分鐘 10 次；通行碼一小時內錯 20 次（不分 IP）整個 AI 先停到那一小時過完；一天最多呼叫 Claude 200 次（`AI_DAILY` 可改，測試連線不算）；每種工作的 `max_tokens` 照要寫的量給。通行碼短於 8 個字時，設定裡會提醒換一組
- 沒料到的錯誤也回 JSON 和 CORS 標頭，前端看得到是伺服器出錯，不會當成連不上

**番茄鐘到點的推播**（`/v1/push/*`，`worker/src/push.js`）：跟同步碼無關，沒開線上同步也能用。一個 Durable Object（`PushHub`）用 alarm 到點送出一則沒有內容的 Web Push，一台裝置同時只排一則；VAPID 金鑰第一次用到時自己產生、存在 Durable Object 裡，不用設 secret（`wrangler.toml` 的 migration 在 `deploy` 時自動套用）。伺服器只收到推播網址和時間，而且只送到瀏覽器廠商的推播服務（Apple、Google、Mozilla、Microsoft 的網域），不能拿來打別的網址；最久排到 6 小時後。每個 IP 每分鐘 40 次、整個伺服器一天最多排 5000 則（`PUSH_DAILY` 可改，取消不算）；推播服務或簽名暫時出錯時留著紀錄讓 alarm 重試，拖過 10 分鐘就放棄

```bash
cd worker
npx wrangler@4 deploy                                     # 部署 Worker
npx wrangler@4 d1 migrations apply hiyori-sync --remote   # 套用 migrations/ 裡的資料表變更
```

開發時可以用 `VITE_SYNC_API=http://localhost:8787 npm run dev` 指到本機的 `npx wrangler@4 dev`。

## Android 殼（android/）

Android 手機上想要「專注時在狀態列、鎖定畫面即時倒數」（Android 16 的 Live Updates，三星手機上是 Now Bar），網頁做不到，所以有一個很薄的原生 App：畫面就是線上的網站（WebView，網站更新它就是新版），多出來的只有通知。

- **即時倒數**：專注、休息中是一則常駐通知，請系統升級成即時通知。倒數由系統自己跑（告訴它幾點結束），App 被收掉也照樣在走，沒有背景服務。暫停時寫還剩多久
- **到點**：用手機的鬧鐘準時發「專注結束／休息結束」，鎖著、沒網路都一樣（不經過 Worker 的推播）
- **提醒**：日程、就寢、重要日子這些，網頁開著時改用原生通知發
- 網頁透過 `window.HiyoriNative` 叫原生（`src/native.js`）；不在殼裡時這段什麼都不做
- 資料存在 App 自己的空間，跟瀏覽器裡的分開：用線上同步輸入同步碼帶過來
- 要不要顯示在 Now Bar 由系統決定：設定 → 通知 → 即時通知裡要允許這個 App；沒顯示的話到開發人員選項找「所有 App 的即時通知」

建置不用 Android Studio、不用 Gradle（JDK 17 以上、Android SDK 的 `platforms;android-36.1` 和 `build-tools;37.0.0`）：

```bash
pwsh android/build.ps1            # → android/build/hiyori.apk
pwsh android/build.ps1 -Install   # 建好後裝到 adb 連著的手機
```

需要 Android 16 以上。簽章用這台電腦的 debug keystore：同一台電腦建的可以直接蓋過去更新。

## 瀏覽器端對端測試（e2e/）

Service Worker 只在正式版註冊，所以這組測試用正式建置跑：開始前先建兩個版本，`e2e/.out/a` 是跟部署一樣的建置（使用者手上的舊版），`e2e/.out/b` 是每個檔名多一段 `-b` 的建置（之後部署上去的新版，`HIYORI_BUILD_TAG=b`）。每個測試開自己的小伺服器（`e2e/server.js`，App 放在 `/hiyori-island/` 子目錄，跟 GitHub Pages 一樣），途中可以換成新版、讓某個檔案回 404，或整台斷線；瀏覽器 context 也是全新的。

- **離線**：App 模式打開過一次後斷網重開，任務還在、離線時新增的也存得下來，月曆和教練（延後載入的畫面）從快取打開；小島模式看過一次小島後斷網重開，小島照樣建得起來
- **自動更新**：開著舊版時部署了新版，新的 Service Worker 接手後舊快取清掉；舊頁面要載入還沒載過的畫面（切回小島）時自動重新整理成新版。手上有打到一半的字時不自動重新整理，改成「重新整理」按鈕、字留著，按了才換
- **新版有檔案下載不到**：新的 Service Worker 裝不起來，舊版和舊快取都留著，斷網重開還是舊版、打得開
- 沒有新版時檢查更新什麼都不動
- **App 模式的主要流程**：一行輸入請ふじ排下週 → 預覽 → 套用變成任務 → 撤銷拿掉；練習曲的任務頁打開「♩ 速度」、填目標，按 ＋ 從一半開始、照節拍器刻度跳，清單上看得到「♩63／120」，打到目標按 Enter 變「達標」並說一聲，重新整理後還在；開了通知的番茄鐘開始時只把推播網址和時間交給伺服器、字留在裝置上，暫停和停掉會取消；番茄鐘開始後重新整理照原本的結束時間接著倒數，停掉後重新整理是待機；專注頁的貓咪從旁邊走進來，點腳印請牠離開後收起來（設定記住），系統開了減少動態效果時在原地睡著不走動

小島用軟體算圖（沒有顯示卡也能跑），同時最多跑 3 個測試；CI 的機器只有 2 核心，一次跑一個（不然會互相拖到逾時）。推上 `main` 時端對端測試沒過就不發布；失敗時的截圖和 trace 在 `e2e/.out/results`（CI 上是 `e2e-results` artifact）。

## 開發用參數

- `?hour=20.5`：預覽指定時刻的天色（不影響資料）
- `?season=winter`：預覽指定季節（spring／summer／autumn／winter）
- `?focus=0.1`：番茄鐘縮短成 0.1 分鐘，方便測試（只在 `npm run dev` 有效）
- `?tab=habits`：直接打開某個分頁（tasks／schedule／habits／projects／records）；`?calendar`：直接打開日曆
- `?classic`：改用舊的程序化角色模型
- Console 裡的 `hiyori.store`、`hiyori.cloudSync`、`hiyori.fileSync`、`hiyori.sky.hourOverride = 6` 可以直接操作
